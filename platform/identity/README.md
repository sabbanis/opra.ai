# Local Identity Seed Data

`users.json` seeds local Company OS identities for browser testing. The file is intentionally small and fake.

Seeded personas:

- `owner`: full access and user administration
- `company_os_admin`: system operations and user administration
- `customer_lead`: Customers module lead
- `customer_operator`: Customers module operator
- `engineering_lead`: Delivery module lead
- `support_engineer`: Delivery support operator
- `people_ops`: People module operator
- `hiring_manager`: People hiring operator

All seeded users use passcode `demo`. Newly registered or admin-created local users are appended to `users.json`.
